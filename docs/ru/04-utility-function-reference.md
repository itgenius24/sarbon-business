# Справочник Utility Функций

## Обзор

Платформа Логистики Sarbon содержит 30+ utility функций, организованных в директории `src/utils/`, предоставляющих важную вспомогательную функциональность для форматирования данных, валидации, интернационализации и UI операций. Этот справочник документирует назначение каждой utility функции, параметры, возвращаемые значения и паттерны использования.

## Категории Utility

### Утилиты Даты и Времени

#### `formatDate(date, dateFormat)`
**Расположение**: `src/utils/formatDate.js`
**Назначение**: Форматирование дат с валидацией и обработкой ошибок
**Параметры**:
- `date`: Объект Date или строка даты для форматирования
- `dateFormat`: Строка формата (по умолчанию: "dd.MM.yyyy")
**Возвращает**: Отформатированную строку даты или пустую строку если невалидна
**Зависимости**: Библиотека `date-fns`
**Пример Использования**:
```javascript
import { formatDate } from '@/utils/formatDate';
const formatted = formatDate(new Date(), 'dd/MM/yyyy'); // "18/06/2025"
```
**Статус**: ✅ Активна - Используется в полях ввода и отображения дат

#### `formatDateTime(date)`
**Расположение**: `src/utils/formatDateTime.js`
**Назначение**: Форматирование datetime с корректировкой часового пояса и относительным отображением времени
**Параметры**:
- `date`: Объект Date или строка даты
**Возвращает**: Отформатированную строку datetime с относительными индикаторами
**Особенности**:
- Корректировка часового пояса (-5 часов)
- Относительное форматирование "Сегодня", "Вчера"
- Отображение времени для недавних дат
**Технический Долг**: 🚨 Содержит debug выражение `console.log('inputDate', inputDate)`
**Использование**: Временные метки грузов, история GPS отслеживания

#### `addDaysToDate(date, days)`
**Расположение**: `src/utils/addDaysToDate.js`
**Назначение**: Добавление указанного количества дней к дате
**Параметры**:
- `date`: Базовая дата
- `days`: Количество дней для добавления
**Возвращает**: Новый объект даты
**Использование**: Расчеты сроков, планирование

#### `isValidDate(date)`
**Расположение**: `src/utils/isValidDate.js`
**Назначение**: Валидация является ли значение валидной датой
**Параметры**:
- `date`: Значение для валидации
**Возвращает**: Boolean, указывающий валидность
**Использование**: Валидация форм, обработка данных

### UI и Визуальные Утилиты

#### `rem(px)`
**Расположение**: `src/utils/common.js`
**Назначение**: Конвертация пиксельных значений в rem единицы для адаптивного дизайна
**Параметры**:
- `px`: Пиксельное значение для конвертации
**Возвращает**: Строку rem значения (например, "1.000rem")
**Реализация**:
```javascript
const rootFontSize = 16;
export const rem = (px) => {
  return px ? `${(Math.abs(px) / rootFontSize).toFixed(3)}rem` : "0rem";
};
```
**Использование**: CSS-in-JS стилизация, адаптивный дизайн

#### `getSVGIcon(tempValue, type)`
**Расположение**: `src/utils/getSVGIcon.js`
**Назначение**: Генерация динамических SVG иконок с встроенным текстом для маркеров карт
**Параметры**:
- `tempValue`: Текст для отображения в иконке (по умолчанию: "$2000")
- `type`: Тип иконки ("occupied_cargo" для синего, по умолчанию зеленый)
**Возвращает**: Строку Data URL для SVG иконки
**Особенности**:
- Динамическое встраивание текста
- Цветовые варианты (синий/зеленый)
- Оптимизация маркеров карт
**Использование**: GPS отслеживание маркеров, индикаторы статуса грузов

#### `isVisibleInViewport(element)`
**Расположение**: `src/utils/isVisibleInViewport.js`
**Назначение**: Проверка видимости DOM элемента в viewport
**Параметры**:
- `element`: DOM элемент для проверки
**Возвращает**: Boolean, указывающий видимость
**Технический Долг**: 🚨 Содержит debug выражение `console.log`
**Использование**: Ленивая загрузка, анимации на основе скролла

## Пользовательские Hooks

### Расчет Расстояний

#### `useGetDistance({ origin, destination, referencePoints })`
**Расположение**: `src/hooks/useGetDistance.js`
**Назначение**: Расчет расстояния и продолжительности между точками с использованием Yandex Maps
**Параметры**:
- `origin`: Координаты начальной точки
- `destination`: Координаты конечной точки
- `referencePoints`: Массив пар координат для многоточечных маршрутов
**Возвращает**: Объект с расстоянием (км) и продолжительностью
**Зависимости**: Yandex Maps API
**Технический Долг**: 🚨 Содержит `console.error` для неудачных расчетов
**Использование**: Планирование маршрутов, оценки доставки

### Язык и Локализация

#### `useGetLang()`
**Расположение**: `src/hooks/useGetLang.js`
**Назначение**: Получение текущего языка/локали приложения
**Возвращает**: Строку текущей локали
**Использование**: Интернационализация, локализация контента

### Hooks Доступа к Данным

#### `useGetStoreData()`
**Расположение**: `src/hooks/useGetStoreData.js`
**Назначение**: Доступ к данным MobX store с интеграцией React
**Возвращает**: Объект данных store
**Использование**: Доступ к глобальному состоянию

#### `useGetUserInfo()`
**Расположение**: `src/hooks/useGetUserInfo.js`
**Назначение**: Получение информации о текущем пользователе
**Возвращает**: Объект данных пользователя
**Использование**: Профиль пользователя, состояние аутентификации

#### `useDebounce(value, delay)`
**Расположение**: `src/hooks/useDebounce.js`
**Назначение**: Debounce изменений значений для оптимизации производительности
**Параметры**:
- `value`: Значение для debounce
- `delay`: Задержка debounce в миллисекундах
**Возвращает**: Debounced значение
**Использование**: Поля поиска, оптимизация API вызовов
