# Документация API Слоя Сервисов

## Обзор

Платформа Логистики Sarbon реализует комплексную архитектуру слоя сервисов с доменно-специфичными API сервисами, пользовательскими React Query hooks и двойной конфигурацией HTTP клиентов. Слой сервисов обрабатывает аутентификацию, логистические операции, управление данными и коммуникацию в реальном времени.

## Архитектура Сервисов

```
Frontend Компоненты → Пользовательские Hooks → API Сервисы → HTTP Клиенты → Backend APIs
```

### Конфигурация HTTP Клиентов

#### Основной HTTP Клиент (`request`)
**Расположение**: `src/services/request/`
**Назначение**: Основная API коммуникация для аутентифицированных запросов
**Особенности**:
- Автоматическая инъекция токенов
- Интерцепторы запросов/ответов
- Обработка ошибок и логика повторных попыток
- Конфигурация базового URL

#### Вторичный HTTP Клиент (`requestInvoke`)
**Расположение**: `src/services/requestInvoke/`
**Назначение**: Специализированный клиент для вызовов логистических функций
**Особенности**:
- Альтернативный механизм аутентификации
- Форматирование запросов, специфичное для логистики
- Пользовательская обработка ошибок

#### HTTP Клиент Аутентификации (`authRequest`)
**Расположение**: `src/services/authRequest/`
**Назначение**: Запросы, специфичные для аутентификации, без требований токенов
**Особенности**:
- Запросы до аутентификации
- Потоки регистрации и входа
- Верификация OTP

## Домены API Сервисов

### 1. Сервис Аутентификации

**Расположение**: `src/services/api/auth/auth.service.js`
**Назначение**: Аутентификация пользователей, регистрация и управление сессиями

#### Методы Сервиса

##### `oneLogin(data)`
- **HTTP Метод**: POST
- **Endpoint**: `/auth/login`
- **Назначение**: Вход пользователя с номером телефона и OTP
- **Параметры Запроса**:
  - `phone`: Номер телефона (string, обязательный)
  - `otp`: Одноразовый пароль (string, обязательный)
- **Структура Ответа**:
  ```json
  {
    "success": boolean,
    "data": {
      "token": string,
      "refresh_token": string,
      "user": {
        "id": string,
        "phone": string,
        "role_id": string,
        "dispatcher_type": string
      }
    }
  }
  ```
- **Обработка Ошибок**: Неверный OTP, заблокированный пользователь, системные ошибки

##### `sendOtp(phone)`
- **HTTP Метод**: POST
- **Endpoint**: `/auth/send-otp`
- **Назначение**: Отправка SMS OTP на номер телефона
- **Параметры Запроса**:
  - `phone`: Номер телефона (string, обязательный)
- **Структура Ответа**:
  ```json
  {
    "success": boolean,
    "message": string,
    "data": {
      "otp_sent": boolean,
      "expires_at": string
    }
  }
  ```

### 2. Сервис Функций

**Расположение**: `src/services/api/functions/functions.service.js`
**Назначение**: Логистические операции, управление грузами и GPS отслеживание

#### Основные Методы

##### `LogistikaGetCargoList(params)`
- **HTTP Метод**: POST
- **Endpoint**: `/functions/LogistikaGetCargoList`
- **Назначение**: Получение списка грузов в соответствии с ролью пользователя

##### `LogistikaAddCargo(cargoData)`
- **HTTP Метод**: POST
- **Endpoint**: `/functions/LogistikaAddCargo`
- **Назначение**: Создание нового заказа груза

##### `LogistikaGpsTrackingFilterDriver(params)`
- **HTTP Метод**: POST
- **Endpoint**: `/functions/LogistikaGpsTrackingFilterDriver`
- **Назначение**: Фильтрация и назначение водителей на основе GPS

## Обработка Ошибок

### Глобальные Интерцепторы Ошибок

#### Интерцептор Запросов
```javascript
request.interceptors.request.use(
  (config) => {
    const token = getAuthToken();
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }
    return config;
  },
  (error) => Promise.reject(error)
);
```

### Типы Ошибок

#### Ошибки Аутентификации
- `401 Unauthorized`: Токен истек или неверный
- `403 Forbidden`: Неразрешенная операция
- `422 Validation Error`: Неверные входные данные

#### Ошибки Бизнес-Логики
- `400 Bad Request`: Неверные параметры запроса
- `404 Not Found`: Ресурс не найден
- `409 Conflict`: Нарушение бизнес-правил

## Соображения Безопасности

### Управление Токенами
- JWT токены хранятся в безопасном localStorage
- Refresh токены в httpOnly cookies
- Автоматический механизм обновления токенов

### Защита Данных
- Все API запросы через HTTPS
- Шифрование чувствительных данных
- Валидация входных данных

## Заключение

Платформа Логистики Sarbon имеет мощный и гибкий слой API сервисов, который обеспечивает:

1. **Комплексную аутентификацию** - JWT, OTP, контроль доступа на основе ролей
2. **Логистические операции** - управление грузами, GPS отслеживание, назначение водителей
3. **Данные в реальном времени** - GPS отслеживание, обновления статусов
4. **Управление файлами** - обработка документов с помощью AI
5. **Оптимизацию производительности** - кеширование, пакетные запросы
6. **Безопасность** - управление токенами, защита данных
7. **Мониторинг** - отслеживание ошибок, анализ производительности

Эта архитектура создает прочную основу для удовлетворения сложных логистических требований платформы.
